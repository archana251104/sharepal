## 📌 About the Project

This project recreates the **SharePal Gaming Gadgets on Rent** experience with a focus on:

- Clean and responsive UI
- Gaming product catalogue
- Product filtering
- Online product images
- Rental date selection
- Product availability
- FAQ accordion
- Testimonials
- Responsive navigation
- Mobile-friendly layout
- Interactive buttons and notifications

The project is inspired by SharePal's Bangalore gaming rental experience.

---

## ✨ Features

### 🎮 Gaming Product Catalogue

The website displays the supplied SharePal gaming products with:

- Product name
- Product image
- Rental price
- Rating
- Booking count
- Product tags
- Availability status

The supplied dataset contains **23 products**.

### 🔎 Product Filters

Users can filter products by:

- All
- PS5 Console
- Xbox Console
- VR
- Big Screen Gaming
- Racing Wheel
- PS5 Games

### 📅 Rental Date Selection

Users can select:

- Rental start date
- Rental end date

The selected dates are displayed in the rental section.

### 🛒 Rental Interaction

Available products include a **Rent** button.

Unavailable products are displayed as:

> Out of stock

### ❓ FAQ Accordion

Frequently asked questions can be expanded and collapsed interactively.

### 📱 Responsive Design

The website adapts to:

- Desktop
- Tablet
- Mobile

### 🖼️ Online Product Images

Product images are loaded directly from SharePal's image CDN, so no local product-image folder is required.
